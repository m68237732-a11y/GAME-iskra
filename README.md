# ИСКРА

Неоновый рогалик-выживалка. Игра целиком живёт в одном файле `index.html`; приложение для Android (`ISKRA.apk`) —
маленькая обёртка, в которую вложены игра и HD-пакет (саундтрек и фоны).

## Как приходят обновления

* Приложение само скачивает `index.html` с ветки `main`, когда в `version.json` растёт `build`.
* HD-пакет (музыка и фоны) едет только внутри APK. Без него игра играет музыку синтезатором и рисует фоны сама —
  так что обновление `index.html` работает и в старом приложении.

* 4 новых оружия с эволюциями: Светлячки → Эскадрилья, Мины → Минное поле, Рикошет → Шальная звезда, Токсин → Чума.
* 3 новых усиления: Фокус, Эхо, Барьер.
* 2 новых босса: Громовержец и Хронос. 4 новых врага: Прыгун, Призыватель, Мортира, Воришка.
* Режим «Блиц»: 5 минут, ускоренный рой, счёт очков.
* Питомцы: 8 спутников со своими талантами.
* 4 реликвии, умение «Звездопад», 3 улучшения в магазине, 3 фона, цвета, титулы, достижения, задание дня.
* 4 новых трека: Полёт, Гром, Часы, Блиц.
* HD-пакет в приложении: 33 композиции (68 минут) и 17 фонов-туманностей.
