# Инструменты сборки ИСКРЫ

Игра — один файл `index.html`. Приложение (APK) — маленькая WebView-обёртка, в которую вложены игра и HD-пакет
(саундтрек и фоны). Android SDK для сборки не нужен: всё делает `build_apk.py`.

| Файл | Что делает |
| --- | --- |
| `wrapper/` | Готовые части обёртки (манифест, ресурсы, `classes.dex`) из приложения 2.9. Не меняются. |
| `build_apk.py` | Прописывает версию в манифест и dex, упаковывает игру и HD-пакет, подписывает APK (v1 + v2). `--verify` проверяет готовый APK. |
| `render_all.js`, `render_lib.js` | Рендерят полные версии всех треков синтезатором самой игры (headless Chromium, Playwright). |
| `encode_music.py` | Выравнивает громкость, ограничивает пики и кодирует рендеры в OGG. |
| `gen_bg.py` | Рисует бесшовные фоны-туманности для каждой темы. |
| `make_pack.py` | Пишет `hd/pack.js` — список содержимого HD-пакета. |

## Как пересобрать

```bash
# 1. саундтрек (≈15 минут): рендер → OGG
node tools/render_all.js index.html            # пишет audio/raw/*.f32
python3 tools/encode_music.py audio/raw hd/music 6
# 2. фоны
python3 tools/gen_bg.py hd/bg 1536
# 3. список пакета и APK
python3 tools/make_pack.py hd
python3 tools/build_apk.py --wrapper tools/wrapper --index index.html --hd hd \
    --version 4.0 --build 400 --code 40 --key iskra-release.p12 --key-pass <пароль> --out ISKRA.apk
```

Готовый HD-пакет можно не рендерить заново, а достать из уже собранного APK: `unzip ISKRA.apk 'assets/hd/*'`.

## Важно

* `--version` — ровно 3 символа (например `4.0`): версия вписывается в обёртку «на месте».
* `--build` должен совпадать с `build` в `version.json`: по нему приложение решает, качать ли обновление `index.html`.
* Ключ подписи (`iskra-release.p12`) в репозитории **не хранится**. Обновить установленное приложение можно только APK,
  подписанным тем же ключом, поэтому файл ключа нужно беречь.
* Обновление `index.html` приходит в приложение само (с ветки `main`), HD-пакет — только вместе с APK.
  Без пакета игра играет музыку синтезатором и рисует фоны сама.
